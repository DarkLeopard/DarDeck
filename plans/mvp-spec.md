# MVP Spec — DarDeck (bound)

## Договорённости
1. Язык ядра — Python 3.12+, без привязки к фреймворку: движок — чистая библиотека.
2. Вся среда разработки/тестов — Docker (docker compose). На хосте только файлы и git-операции.
3. Приватность-политика README binding: чувствительные паки, картинки, токены — вне git; `.env` игнорируется; токен бота передаётся только через env.
4. Публичный API-стиль: движок не знает про Telegram — только доставка через `Sender`-интерфейс.
5. Тесты обязательны на каждый модуль; команду тестов см. в плане.

## Домены
- **User**: id, username, is_premium, premium_until (дни-гранты — накопление свободных дней).
- **Pair**: двое Users, у пары общий контекст показанных карточек; пользователь максимум в одной активной паре (MVP).
- **Card**: id, theme, text, source (seed/ugc), author_id?, visibility (private/public), status (draft/pool/retired), image_ref?
- **CardSource adapter**: `fetch_candidates(pair, policy) -> list[Card]` поверх произвольного хранилища.
- **RulePlugin**: `select(card, history, policy) -> Card` — как выбирать из кандидатов.

## Политика выдачи (binding для README)
- Решает сервер: `DeliveryPolicy = {interval, cards_per_cycle, allow_user_control}`.
- free: серверные интервалы (по умолчанию 1 карточка/день), юзер частоту не меняет.
- premium: сервер отдал юзеру контроль частоты/количества в заданных лимитах.
- grant premium-дней: +1 день за UGC-карточку с 10 like/0 dislike (антифарм: лайк/дизлайк может ставить только получатель карточки в паре).

## Выдача
- `issue_card(pair)` → одна карточка: не та же, что уже показывалась паре (по тексту-идентификатору), приоритет пула, потом seed.
- Спонсорская карточка: обычная Card c флагом `is_sponsored`, лимит: ≤1 спонсорская на N=7 показов в паре.
- Учёт: issued, completed, rated(like/dislike/review), история показов пары.

## UGC
- Создание карточки: private (только паре автора) или public (в очередь пула).
- Автодобавление в пул: 10 like и 0 dislike → status=pool.
- Пост-модерация: ≥3 report → status=retired (не выдаётся), логируется.
- Рейтинг/отзывы: оценка +1/0/-1, опциональный текст-отзыв; чистка: карточки со средним <0 при ≥5 оценах попадают в ревью-список (`tools/cleanup` печатает, удаляет только с `--confirm`).

## Доставка
- `Sender` интерфейс: `send(user, card)`. Telegram-бот (aiogram 3) реализует его поверх движка; в тестах — MockSender. Боевой токен — только env `DARDECK_BOT_TOKEN`; без токена бот поднимается в dry-run (логгирует вместо отправки).

## Не в MVP (следующие фазы)
- Оплата/биллинг премиума (только флаг is_premium в данных), веб-интерфейс, генерация картинок, несколько пар на юзера, спонсорский кабинет.
