# Delight

Движок ежедневных карточек-фантов для пар. Каждый участник раз в день получает
карточку с заданием — способом порадовать свою вторую половинку.

## Архитектура

Движок отделён от контента и правил:

- **Движок** (ядро): выдача карточки раз в день пользователю/пару, учёт
  выполнений, история, рециркуляция невыполненных.
- **Плагин БД**: хранилище карточек на тематику (адаптер — любая база/источник).
- **Плагин правил выдачи**: как выбирать карточку (случайно, по категориям,
  ротация, ограничения пары, донат-приоритет).
- **Боты**: телеграм-боты разной тематики поверх одного движка; веб-интерфейс
  для добавления карточек.

## Монетизация (ненавязчивая)

1. Нативная реклама в карточке: «Фант: подари цветы» → спонсор доставки цветов.
   Рекламодатель = источник реального действия, полезного паре.
2. Донаты напрямую автору.
Реклама ограничена: не чаще N карточек с брендом, без навязчивых баннеров.

## Состав репозитория (план)

- `engine/` — ядро движка
- `adapters/db/…` — адаптеры хранилищ
- `adapters/rules/…` — наборы правил выдачи
- `bots/telegram/…` — боты-темы
- `web/…` — веб-интерфейс управления карточками
- `docs/` — схемы, дизайн правил, реклама/партнёрство
